# desktopirates

デスクトップの片隅に常駐する、円盤状の海を舞台にしたローポリ・レトロ3D冒険RPGです。Unity 6で制作しています。

## 現在の内容

- 枠のない透過Windowsオーバーレイ
- 現在時刻に連動する「メニューサークル」：ドラッグで移動、クリックでメニュー表示
- 音量、表示サイズ、海図、保存、終了を備えた円形メニュー
- シードとチャンク座標から復元する無限航海マップ。航海図は中央の透過円形オーバーレイで、外枠を持たず表示中も航行可能
- 港、敵船、残骸、宝、4種のボス、砲撃、修理、食料・水、船体改良
- 筏から大型船まで6段階のShip Levelと、船体断面・船尾楼・帆装・索具・砲門が成長するBlender製v03専用モデル／ドットテクスチャ
- 通常敵8船種を、船幅・全長・帆装・武装まで役割別に作り分けたBlender製v04敵艦モデル。色替えではなく輪郭から敵クラスを判別可能
- 砲台・舵・帆・碇への乗員配置、役割パーク、ボス周回ドロップ
- 5秒間その場で炎上してから3秒かけて沈む、ワールド座標固定の撃沈演出
- 見切れた目的地を距離に応じた大きさで示す円周タグ
- 朝・昼・夕方・夜に変化する海、照明、メニューサークル
- 探索差分だけを保存する小容量バイナリセーブ

## 操作

- `Tab`：スクロール式の船倉インベントリを開く／閉じる（右側のバッグボタンでも操作可能）

- `W`：巡航速度を1段階上げる（キーを離しても前進を継続）
- `S`：巡航速度を1段階下げる（0で停止、後退はしない）
- `A / D`：旋回
- `Q / E`：カメラを45度回転
- `F`：港へ入る / 残骸・宝を回収（航行速度に関係なく回収可能）
- `Space`：`ATTACK MODE` / `WATCH MODE` を切り替える。攻撃モードでは、射界・射程・装填が整った砲台が個別に自動射撃
- メニューサークルをクリック：メニュー開閉
- メニューサークルをドラッグ：ゲーム全体を移動
- `Esc`：メニューを開く／閉じる（別画面を開いている場合は、その画面を閉じる）

港の `SHIPYARD` → `GUN DECK` では6つの砲座を選択し、砲台の搭載・収納、威力、装填速度、射程、砲弾種を個別に変更できます。メニューの `LANGUAGE` から日本語と英語を切り替えられます。船名、`SHIPYARD`、`ATTACK MODE` など世界観を支える航海用語は、没入感を優先して両言語で一部共通表記にしています。

積載重量に数えるのは、搭載中の砲台、装甲、推進・旋回設備、船員などの船体構成だけです。食料、水、資材、回収品、パーク、船倉の予備砲台はインベントリ品として扱い、積載量や航行性能に影響しません。チュートリアルの筏にも船首砲を1門搭載できます。
- `F2`：時間帯表示を6時間進める（開発確認用）

開始時の最高巡航段階は3です。港の機関改良を購入するたびに最高段階が1つ増え、最大速度も上昇します。起動直後と港への曳航後は安全のため停止状態になります。

## プロジェクト構成

```text
Assets/Desktopirates/
├─ Art/          コンセプトアートと制作元資料
├─ Resources/    実行時に読み込むテクスチャ・マテリアル
├─ Scenes/       起動シーン
├─ Scripts/      Runtime / Editor
├─ Shaders/      海・帆などの専用シェーダー
└─ Tests/        EditModeテスト
Docs/            仕様、実装、保存形式、アート運用
Builds/Windows/  Windows実行ファイル
```

実行ファイルは `Builds/Windows/desktopirates.exe` です。セットアップとGitの手順は `Docs/SETUP_AND_GIT.md`、アート制作規約は `Docs/ART_PIPELINE.md` を参照してください。
船級・乗員・ボスの仕様は `Docs/SHIP_CREW_BOSS_EXPANSION.md` にまとめています。
