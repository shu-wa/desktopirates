# desktopirates

デスクトップの片隅に常駐する、円盤状の海を舞台にしたローポリ・レトロ3D海洋冒険RPGです。

## 現在実装されているもの

- 枠なし・透過・最前面のWindowsオーバーレイ
- 朝／昼／夕方／夜を現す「メニューサークル」
- メニューサークルのドラッグ移動、クリックで開く丸型メニュー
- 音量、表示サイズ、海図、保存、終了
- シードとチャンク座標から作る無限ワールド
- 距離に応じて大きさが変わる円周上のイベントタグ
- 港、残骸、宝、敵船、砲撃、修理、補給、機関／大砲強化
- 探索区間とイベント差分だけを保存する省容量バイナリセーブ
- 実時間に連動する海と照明
- 45度単位・8方向のカメラ回転

## 操作

- `W / S`：前進／後退
- `A / D`：旋回
- `Q / E`：カメラを45度回転
- `F`：港へ入る／残骸や宝を回収（接近して低速時）
- `Space`：射程内の敵へ砲撃
- メニューサークルをクリック：メニュー開閉
- メニューサークルをドラッグ：ゲーム全体を移動
- `Esc`：開いているメニューを閉じる
- `F2`：時刻表現の確認用プレビュー

Windows版は `Builds/Windows/desktopirates.exe` です。詳しい起動・開発・Git手順は `Docs/SETUP_AND_GIT.md` を参照してください。
