# 船長記録・敵種・変異海域・ボス変異

## 船長記録

メニューサークルの `LOG` から開く。次の値を恒久記録する。

- 航海距離、海図化済みチャンク数
- 与えたダメージ、獲得 GOLD
- 撃沈した通常敵の合計と種類別内訳
- ボスの種類別撃破数と変異別撃破数
- 回収した残骸、発見した宝、寄港回数
- 発見済み変異海域

セーブ形式は Version 7。記録は集計値とビットマスクだけを可変長整数で追記する。Version 6以前のセーブは記録値0として互換読み込みする。

## 通常敵アーキタイプ

| 種類 | 戦い方 |
|---|---|
| Corsair | 標準型 |
| Skirmisher | 低耐久・高速・短いリロード |
| Gunboat | 鈍足・長射程・高威力 |
| Fire Raider | 炎上弾を使用 |
| Plague Raider | 船員性能を下げる毒弾を使用 |
| Frost Cutter | 船速を下げる凍結弾を使用 |
| Ironclad | 高耐久・低速・高威力 |
| Hunter | 高速追跡・粘着弾を使用 |

遠方へ進むほど候補が増える。同じワールドシードと座標では同じ種類になる。帆色、船体サイズ、砲、火壺、薬樽、氷晶、装甲帯などの外見差を持つ。

## 変異海域

6チャンク単位の大海域ごとに決定的に生成する。開始港周辺は必ず `Calm Waters` とする。

| 海域 | 主な効果 |
|---|---|
| Calm Waters | 補正なし |
| Tempest Belt | 旋回低下、敵加速・速射 |
| Miasma Shoals | 船速低下、毒敵の出現率増加 |
| Frostwake | 船速低下、凍結敵の出現率増加 |
| Tar Sea | 旋回大幅低下、重装敵の出現率増加 |
| Ember Current | 船速上昇、炎上敵の出現率増加 |

海面色、通常航海HUD、地図の既知海域色、敵生成、船速、旋回、敵速度とリロードへ反映する。初発見時は船長記録の海域アトラスへ追加する。

## ボス変異

全ボスに次のいずれかを決定的に付与する。

- Armored: 最大HP増加
- Frenzied: 攻撃力上昇、リロード短縮
- Swift: 移動速度上昇、リロード短縮
- Corrupted: HP・攻撃・状態異常強度・報酬上昇

変異名を敵HUDへ表示し、変異色の封印をボスモデル周囲へ配置する。撃破数は船長記録へ保存する。

## 円周マーカー

距離7から60論理単位の範囲を滑らかな補間曲線で縮小する。

- 近距離: 最大94px
- 遠距離: 最小30px
- 遠距離ほど透明度も低下
- 方角は従来どおり船を中心とした円周位置で表し、矢印は使用しない
