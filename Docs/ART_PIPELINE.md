# アート制作パイプライン

## ビジュアル方針

コンセプトアート v04 を基準に、濃紺のデスクトップ空間、真鍮色のUI、青緑の円盤状の海、45度俯瞰の帆船を共通言語にします。画面全体は「ローポリ3Dの面構成」と「ポイントフィルタのドット表現」を組み合わせ、細部を増やしても輪郭の読みやすさを優先します。

## フォルダと責務

- `Art/Concept`：承認済みのコンセプト画像。実装から直接参照しません。
- `Resources/Textures/Environment`：海面など、ランタイムでロードする環境テクスチャ。
- `Resources/Textures/UI`：必要になった外部UIテクスチャ。現状のアイコンはコード生成です。
- `Resources/Materials`：シーン構築時の基準マテリアル。
- `Shaders`：スタイルを決める専用シェーダー。
- `Scripts/Runtime/ProceduralSceneFactory.cs`：低ポリ船・港・残骸・宝の組み立て。
- `Scripts/Runtime/UiTextureFactory.cs`：真鍮UI、アイコン、タグのコードネイティブ生成。
- `Scripts/Editor/DesktopiratesArtImporter.cs`：用途別のUnityインポート規則。

## 制作フロー

1. コンセプトでシルエット、色、情報の優先順位を確定する。
2. ラスター素材は用途を1つに限定して生成・制作し、UIや物体を混在させない。
3. `用途_特徴_vNN` で命名し、元画像は `Art`、実装用は適切な `Resources/Textures` に置く。
4. Unityの自動インポーターで Point / Uncompressed / No MipMap を適用する。
5. シェーダーで時間帯の色を掛け、昼・夜の両方で輪郭が潰れないことを確認する。
6. 720 × 760 の実機キャプチャで、透過、タグ、メニュー開閉、重なりを検品する。

## 現在の表現方法

- 海：生成した青緑テクスチャを専用シェーダーで2層スクロールし、ファセット・泡・ディザを合成。
- 船・港・イベント：Unityプリミティブと小さな専用メッシュからランタイム生成。木材・帆布・石材の共用テクスチャ、共通パレット、ハードシャドウを使用。
- UI：円、ピル、菱形、グリフを `Texture2D` へ描画し、Pointフィルタで表示。外周は3段階の真鍮ベベル。
- 時間帯：実時計から朝・昼・夕方・夜のパレットを補間し、海、環境光、太陽、メニューサークルへ反映。

## 品質チェック

- 海の円盤外は完全透過で、矩形背景を出さない。
- メニューサークルのクリックとドラッグを混同しない。
- UIは海や船より前面、タグは円周上、HUDは船を隠さない。
- 720 × 760で文字とアイコンが判別できる。
- 新しいラスター素材は生成プロンプト・参照元・配置先を記録する。
- マテリアル用原画は高解像度で保持し、Unityでは最大512pxへ縮小してGPUメモリを抑える。
