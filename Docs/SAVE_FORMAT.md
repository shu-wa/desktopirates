# 無限マップと省容量セーブ設計

## 方針

基礎マップは保存しません。`worldSeed + chunkX + chunkY + salt` を64bitハッシュへ変換し、イベント種別・座標・報酬を毎回同じ結果で再生成します。そのため、無限ワールドでも地形データ量はゼロです。

保存する差分は次だけです。

- 船の座標、向き、資金、船体、補給、強化レベル
- 探索済みチャンク
- 回収／撃破済みイベントID

## 変換

- 座標：1/16ワールド単位へ固定小数点化
- 符号付き整数：ZigZag変換
- 全整数：Varint（可変長整数）
- 探索済みチャンク：Y行ごとにXの連続範囲を `(開始差分, 長さ)` でRun-Length Encoding
- イベントID：昇順に並べ、直前IDとの差だけをVarint保存
- 全体：Deflate圧縮

ファイルは `voyage.dprs`、バージョン付きバイナリです。一時ファイルへ書いてから置き換えるため、保存中断で本体が壊れにくくなっています。破損検出時は `.broken` を残して新規航海へ安全復帰します。

テストでは、連続した945チャンクと解決済みイベント300件を含む状態が1.6KB未満になることを検証しています。
