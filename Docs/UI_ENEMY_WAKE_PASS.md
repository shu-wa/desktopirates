# UI・敵情報・航跡 改修仕様

## 目的

- HP、GOLD、船員、積載量を、最大桁でも真鍮枠からはみ出さず読めるようにする。
- 記号だけでは意味が伝わらない操作には短いラベルを残す。
- UI アイコンの見かけの大きさを統一する。
- 敵の強さと残り体力を、戦闘前と戦闘中のどちらでも判断できるようにする。
- 船の航跡を船体に貼り付けず、実際に通った海面へ一定時間残す。

## 共通寸法

`UiLayoutMetrics` を UI 寸法の単一の基準とする。

- 基本アイコン: 40 px
- HUD カード: 166 x 76 px
- HUD カード間隔: 176 px
- 敵情報プレート: 184 x 48 px

HUD の真鍮枠には `tooltip_card` を使い、アイコン、ラベル、値を別領域に配置する。値は最大 HP 10,000、GOLD 999,999 の状態でも枠内へ収める。

港は `REPAIR`、`FOOD`、`WATER`、`ENGINE`、`SHIPYARD` の短いラベルを残す。アイコンは判断を速める補助であり、未知の記号を覚えさせる代替物にはしない。

## 敵情報

画面内の敵船の上に次を表示する。

- `LV` とレベル
- 敵名
- 現在 HP を示す色付きバー

通常敵の名前とレベルは、無限生成 ID、距離、報酬から決定的に生成する。同じワールドシードと座標では同じ敵情報になる。ボスは固有名と固定基準レベルを持つ。

## 航跡

航跡は論理マップ座標上の船尾位置を一定距離ごとに記録する。各記録から左右一対の小さな波片を生成し、5.8 秒で消える。

- 船速が低すぎる時は生成しない。
- 0.28 論理単位進むごとに生成する。
- テレポート相当の移動は線で結ばない。
- 航跡はカメラ回転時にも元の海面座標へ残る。
- 円盤状の海の外へ出た航跡は表示しない。
- 旧 Ocean シェーダーの船体追従型の後部模様は削除する。

## 検証条件

- HUD 最大値プレビューで全ラベルと値が枠内にある。
- 港画面でアイコンと短いラベルが併記される。
- 全ボスに名前、レベル、HP バーが出る。
- 航行後に船尾から過去の通過位置へ航跡が連続し、停止後に消える。
- EditMode テスト 93 件がすべて成功する。
