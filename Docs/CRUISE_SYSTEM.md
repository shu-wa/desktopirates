# 自動巡航システム

## 目的

デスクトップ常駐ゲームとして、キーを押し続けなくても航海が進む操作にします。プレイヤーが仕事や別の作業へ戻っても船は選択した速度で進み、目的地へ近づいた時だけ操作へ戻れる設計です。

## 操作と安全性

- `W`を押すたびに巡航段階を1つ上げる。
- `S`を押すたびに巡航段階を1つ下げる。
- 段階0は停止。0より下にはならず、後退操作は存在しない。
- `A / D`の旋回は従来どおりで、巡航中も使用できる。
- 起動直後は停止し、前回終了時の速度を勝手に再開しない。
- 港へ曳航された時は巡航段階と実速度を0へ戻す。
- HUDの `SPD 現在段階/最高段階` で放置前にも状態を確認できる。

## 速度規則

- 初期最高段階：3
- 1段階あたりの目標速度：1.15
- 初期最高速度：3.45
- 機関改良1回につき最高段階を1つ追加
- 機関改良の上限：5回（最高8段階、最高速度9.20）
- 加速は穏やか、減速はやや速くし、停止操作への反応を優先

速度規則は `CruiseModel.cs` に集約し、入力、HUD、港の価格表示、自動テストで共有します。機関改良時に現在段階は変えないため、購入直後に船が意図せず加速することはありません。

## 検証

- 巡航段階が0未満にならないこと
- 機関改良で最高段階と最高速度が増えること
- W相当の入力を1回だけ与え、追加入力なしでも次の更新で前進を続けること
- 全既存システムを含むEditModeテストを通すこと
