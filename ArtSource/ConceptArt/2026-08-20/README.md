# desktopirates concept direction — 2026-08-20

These seven production references define one consistent visual target: a frameless circular sea overlay, a 45-degree isometric low-poly world, crisp 32-bit pixel clusters, selective aged-brass UI, dark navy surfaces, and readable interaction-first hierarchy.

8. `08-menu-circle-settings.png` — click-versus-drag behavior, volume, discrete deferred size presets, map and exit.

## Shared final prompt direction

- Use case: `stylized-concept` for gameplay scenes and `ui-mockup` for interface sheets.
- Camera: fixed 45-degree isometric top-down.
- Medium: crisp 32-bit pixel art fused with simple low-poly 3D; authored wood, canvas, brass and ocean textures.
- Surface: the circular sea floats directly over a dark desktop; never add rectangular window chrome.
- UI: brass only for major frames, buttons and active controls; flat navy list content; consistent icon sizes; generous spacing; no clipping.
- Markers: placed on the exact sea circumference by bearing, no arrows, and smaller with distance.
- Effects: readable and restrained; preserve ship silhouettes and world-coordinate continuity.
- Avoid: photorealism, smooth glossy mobile rendering, UI overlap, illegible microtext, redundant icon frames and watermarks.
